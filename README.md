# 刘老师 · AI传道人 · 个人作品展示网站

单文件个人网站：**7 件 AI 作品 · 4 部著述 · 扫码相连**。

## 特性

- 三套皮肤：纸（新中式宣纸）/ 夜（暗色科技）/ 雪（瑞士极简），右下角调色盘切换，选择本地记忆
- 两种布局：卷轴（编辑部级列表）/ 卡片（作品集网格），同一面板切换
- 扫码相连：微信个人号 / 公众号「AI传道」/ 知识星球「AI产品和架构」，点击灯箱放大
- 零依赖单文件：二维码以 Base64 内嵌 `index.html`，双击即开，离线可用
- 响应式适配移动端，支持 `prefers-reduced-motion`

## 目录

- `index.html` — 网站本体（单文件）
- `images/` — 二维码原图
- `想法.md` — 需求原始笔记

## 预览

浏览器直接打开 `index.html`。

## 部署

Vercel / Netlify / GitHub Pages 导入本仓库即可零配置上线。

## 维护

产品与书籍信息集中在 `index.html` 的「七件作品」「四卷著述」两个章节，直接改文字即可。
